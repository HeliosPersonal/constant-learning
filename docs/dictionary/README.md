# Словник для персонального тренера

Оновлено: 2026-11-01. **Контент готовий за погодженим стандартом: 2 000 унікальних схвалених лем.** Це підготовлений випуск для імпортера T20; новий імпортер і персональний trainer ще не реалізовані.

## Готовий набір

- [course.csv](./course.csv) — 2 000 записів зі статусом `approved`: частина мови, рід або позначка множини, український відповідник, польська відповідь, наближена вимова та авторський приклад з перекладом.
- [evidence.jsonl](./evidence.jsonl) — 2 000 зв’язаних доказів: сторінка й конкретне значення Wikisłownik, українські варіанти джерела, IPA, контрольні суми та походження редактури.
- [readiness.json](./readiness.json) — машинний звіт із кількістю, станом готовності й SHA-256 CSV та доказів.
- [editorial-decisions.jsonl](./editorial-decisions.jsonl) — вихідні редакторські рішення, з яких будується випуск. ID у CSV стабільний за лемою; це редакторський ключ, а не UUID первинного ключа БД.
- [review-changes.jsonl](./review-changes.jsonl) — 116 знахідок незалежного другого LLM-проходу, два фінальні уточнення та застосовані зміни.
- [review-queue.csv](./review-queue.csv) — 108 відкладених записів із причинами; вони не входять до курсу. Поза випуском залишаються також 15 придатних резервних карток у редакторських рішеннях.
- [content-schema.md](./content-schema.md) і [editorial-template.csv](./editorial-template.csv) — формат і критерії подальших змін.
- [sources-manifest.json](./sources-manifest.json), [NOTICE.md](./NOTICE.md) — джерела, контрольні суми знімків, метод та атрибуція.

Розподіл 1 600/400 скасовано. Поточний набір належить до загального повсякденного курсу; це не спеціалізований набір 400 юридичних термінів. Словосполучення й діалоги не зараховуються до 2 000 лем. [Локальні відповідники](./local-equivalents.md) залишаються окремою довідкою.

## Що означає approved

Користувач окремо погодив **джерельну звірку Wikisłownik + LLM-редактуру** замість попередньої вимоги звірки кожного запису з WSJP PAN та перевірки кожного речення в незалежному корпусі.

Для кожної картки редактор зіставив значення з українським відповідником та джерельним ужитком, уклав новий короткий польський приклад і його переклад, звірив наближену вимову з IPA. Усі 2 020 придатних первинних і резервних карток пройшли другий LLM-прохід. Після нього ще чотири картки відкладено; фінальна перевірка вилучила ще одну з невизначеною частиною мови. До випуску відібрано 2 000 із 2 015 придатних. Метод не видається за незалежну перевірку носієм мови або повну нормативну й корпусну перевірку.

Джерело не схвалюється механічно: відсіяно, зокрема, хибних друзів, розірвані переклади й непобутові омонімні значення (`bez`, `lekcja`, `brązowy` та ін.). Частотний KWJP-ранг визначає порядок серед придатних записів, а не схвалення. Пошук кандидатів охоплював перші 8 000 KWJP-написань; це відредагована добірка, а не всі перші 2 000 рядків корпусу.

## Локальна перевірка готовності

З кореня репозиторію, Python 3.11 або новіший, без додаткових пакетів:

```powershell
python -X utf8 tools/dictionary/validate_release.py --directory docs/dictionary --target 2000
python -X utf8 -m unittest discover -s tools/dictionary -p 'test_*.py'
```

Валідатор перевіряє кількість унікальних лем, ID, заповнення полів, статуси, частотний порядок, відповідність перекладів доказам, IPA/значення, мови прикладів, невикористання дослівного джерельного прикладу й контрольні суми. Він не підміняє редакторську оцінку природності речень.

## Відтворення джерельної звірки й випуску

Великі зовнішні знімки не зберігаються в Git. Потрібно близько 141 MB завантаження та місце для локального кешу. Дійсні байти знімків зафіксовані в manifest; якщо постачальник оновив файл і SHA-256 змінився, автоматичного перенесення старих схвалень немає. Для ідентичного відтворення потрібен збережений знімок із указаною сумою.

```powershell
$dictionaryManifest = Get-Content docs/dictionary/sources-manifest.json -Raw | ConvertFrom-Json
$wikiSource = $dictionaryManifest.sources | Where-Object name -eq 'plwiktionary.jsonl.gz'
$frequencySource = $dictionaryManifest.sources | Where-Object name -eq 'kwjp-lemmas.csv.gz'
python -X utf8 tools/dictionary/prepare_sources.py --cache .dictionary-cache --expected-wiktionary-sha256 $wikiSource.sha256 --expected-frequency-sha256 $frequencySource.sha256
python -X utf8 tools/dictionary/build_release.py --sources .dictionary-cache/all-source-supported.jsonl --editorial docs/dictionary/editorial-decisions.jsonl --output docs/dictionary --target 2000 --approve-source-backed
python -X utf8 tools/dictionary/validate_release.py --directory docs/dictionary --target 2000
```

`prepare_sources.py` створює лише кандидатні докази, а не схвалення. Нові чи виправлені редакторські рішення мають пройти джерельну й семантичну перевірку перед перебудовою. При нестачі записів або непогодженому стандарті збирач завершується відмовою й не публікує новий CSV.

## Старий формат застосунку

`ConstantLearning/Resources/Words/words-polish-ukrainian.csv` поки залишається потрібним чинному груповому `WordImportService`. Його 1 200 старих рядків не зараховуються до нового випуску та не вважаються схваленими. Новий `course.csv` не підкладати під старий імпортер: він не підтримує цю схему й повноцінний CSV із комами в полях. T20 перемикає джерело, T43 прибирає стару модель.

Старі дублюючі legacy-огляди, кандидатний список на 2 000 написань, первинну чернетку, пілотний журнал live-запитів і неперевірені діалоги прибрано. За потреби їх можна відновити з історії Git; актуальні стан і докази містяться у файлах вище.
