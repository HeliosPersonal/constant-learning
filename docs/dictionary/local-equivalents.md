# Локальні відповідники для понять у Польщі

Правило картки: спочатку показувати стандартний український відповідник; поширений у Польщі місцевий варіант — другим, як допомогу для впізнавання повсякденного мовлення. Ці нотатки не є юридичними інструкціями.

| Польське поняття | Стандартний український відповідник | Місцевий варіант у Польщі | Примітка |
|---|---|---|---|
| `urząd` | державна установа; у контексті — відповідна установа/орган | ужонд | В основному перекладі й прикладі починати зі стандартного українського відповідника. |
| `karta pobytu` | посвідка на проживання | карта побиту | Словосполучення, не окрема лема; для леми `karta` залишити значення «картка». |

## Звірені джерела

- [Словник української мови: «уряд»](https://sum.in.ua/s/urjad) фіксує значення «державна установа»; для `urząd` у прикладі використано природне уточнення «державна установа».
- [Підляський воєводський уряд — українська інформація](https://www.gov.pl/web/uw-podlaski/infolinie-dla-obywateli-ukrainy------) уживає місцевий варіант «карта побиту».
- [Сілезький воєводський уряд — українська сторінка про CUKR](https://www.katowice.uw.gov.pl/usluga/informacja-dla-obywateli-ukrainy-karta-pobytu-cukr/posvidka-na-prozhivannya-cukr) послідовно вживає «посвідка на проживання».
