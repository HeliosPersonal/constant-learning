# T15 — SPA: вибір/перемикання мови + порожній початковий стан

**Шар:** ui · **Залежить від:** [T13](./T13-set-active-scope-existing.md) · **AC:** AC-01, AC-03, AC-07 · **Оцінка:** L · **Фаза:** 6 (UI)

## Why

US-01/US-02: learner обирає мову й перемикає активну; UI-розміщення — **OQ-2**
([PRD §8](../PRD.md#8-open-questions), [SAD §5 SPA](../sad.md)). «Сьогодні» має показувати стан лише
активної мови й зрозумілий порожній стан для свіжообраної (AC-07). Споживає операції T11/T12/T13.

## What

- Екран/перемикач вибору мови (вибір зі списку `listTargetLanguages`, недоступні — задизейблені з поясненням AC-02).
- Додавання нової мови (`startLearnerLanguage`) і перемикання активної (`setActiveLanguage`) — розміщення за рішенням OQ-2.
- «Сьогодні» рендерить стан активної мови; лічильники інших мов не показуються (AC-07).
- Порожній початковий стан нової мови з першими новими словами в межах daily new words limit.
- Дві теми / Telegram UI kit / узгоджена дизайн-система (без зміни палітри).

## Definition of Done

- [ ] Learner обирає мову й бачить «Сьогодні» активної (AC-01); перемикання оновлює екрани на нову мову (AC-03).
- [ ] Недоступна мова (AC-02) не дає почати, показує пояснення; активна лишається.
- [ ] Порожній стан свіжообраної мови без лічильників інших мов (AC-07).
- [ ] OQ-2 зафіксовано (де перемикач і де додається мова); локальні перевірки (lint/build/typecheck) зелені.
- [ ] Клієнтська телеметрія вимірює p95 перемикання/«Сьогодні» (NFR ≤1500 ms).
- [ ] PR ≤500 LOC.
