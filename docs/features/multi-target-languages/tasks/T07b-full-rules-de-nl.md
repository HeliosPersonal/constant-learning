# T07b — Повні правила нормалізації/форм для de/nl

**Шар:** domain · **Залежить від:** [T07a](./T07a-generalize-forms-pl-en.md) · **AC:** AC-08 · **Оцінка:** M · **Фаза:** 3 (Content)

> Друга реалізаційна задача узагальнення форм/нормалізації. Спирається на узагальнений діспетч
> профілів з [T07a](./T07a-generalize-forms-pl-en.md) і джерела з [T07s](./T07s-spike-language-sources.md).
> **OQ-5** закрито: повні мово-специфічні правила de/nl кодуються одразу.

## Why

AC-08 застосовна до всіх чотирьох мов. Після того як [T07a](./T07a-generalize-forms-pl-en.md) зняв
хардкод і довів узагальнення на pl/en, лишається закодувати **повні** мово-специфічні правила для
de/nl, які не зводяться до en-профілю: рід `der/die/das`, артиклі `de/het`, капіталізація іменників,
складені слова ([SAD §11 OQ-5 resolved](../sad.md#11-risks-and-technical-debt)).

## What

- Профіль **de**: рід `der/die/das`, капіталізація іменників, складені слова — у нормалізації й пошуку форм.
- Профіль **nl**: артиклі `de/het`, капіталізація, складені слова.
- Правила вмикаються через той самий діспетч `normalization_profile`, що й у [T07a](./T07a-generalize-forms-pl-en.md) (без зміни узагальненого коду).
- Для мови з профілем, у якої контенту ще немає, задача дає робочий каркас нормалізації; увімкнення
  (`is_enabled`) лишається за наявністю approved-контенту (не предмет цієї задачі).

## Definition of Done

- [ ] Правила de (рід, капіталізація, складені слова) покриті unit-тестами нормалізації.
- [ ] Правила nl (артиклі `de/het`, капіталізація, складені слова) покриті unit-тестами нормалізації.
- [ ] Integration-тест: нормалізація й пошук за формами для de і nl дають мово-свідомий результат.
- [ ] PR ≤500 LOC.
