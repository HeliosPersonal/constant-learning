# T07 — Узагальнення пошуку форм і нормалізації (зняти хардкод `"pl"`) + правила de/nl

**Шар:** domain · **Залежить від:** [T05](./T05-migrate-content-entries.md) · **AC:** AC-08 · **Оцінка:** L · **Фаза:** 3 (Content)

> **Розблоковано (2026-11-04).** **OQ-5** = **повні мово-специфічні правила для de/nl реалізуються
> одразу** (рід `der/die/das`, `de/het`, капіталізація іменників, складені слова); профілі
> `normalization_profile` для de/nl = `'de'`/`'nl'` (не NULL), AC-08 застосовна до всіх чотирьох мов.
> **OQ-7** = **spike-крок на початку задачі** відбирає вільно-ліцензовані джерела (Wiktionary / Unimorph /
> CC-корпуси) для en/de/nl і фіксує профілі перед кодуванням. Див. [PRD §8 OQ-5/OQ-7](../PRD.md#8-open-questions).
> **Обсяг:** якщо spike + повні правила de/nl виводять PR за 500 LOC — розбити на T07a (узагальнення pl/en)
> + T07b (правила de/nl).

## Why

Наявний мово-свідомий субстрат пошуку (`search_forms.lang`/`morph_forms.lang`) перевикористовується,
але код містить хардкод `"pl"` у `SearchFormsProjection`/морфологічному імпортері
([ADR-0004](../adr/0004-model-supported-languages-as-config-table.md), [SAD §4 стовп 4](../sad.md),
[data-model.md §Indexes](../data-model.md)). AC-08: підказка, приклад, прийняті варіанти й нормалізація
відповіді мають відповідати активній мові, а не польській.

## What

- **Spike (OQ-7, перший крок):** відібрати й зафіксувати вільно-ліцензовані per-language джерела
  (морфологічний лексикон, частотний корпус, довідкове джерело автозвірки) для en/de/nl; результат —
  задокументовані профілі `normalization_profile` `'en'`/`'de'`/`'nl'`.
- Зняти хардкод `"pl"`: `SearchFormsProjection` і морфологічний імпортер беруть мову з
  `target_languages.normalization_profile` / контексту запису, не з константи.
- Нормалізація відповіді застосовує правила профілю активної мови.
- **Повні правила de/nl (OQ-5):** рід `der/die/das`, артиклі `de/het`, капіталізація іменників,
  складені слова — реалізуються одразу; AC-08 застосовна до всіх чотирьох мов.
- Для мови з профілем, у якої контенту ще немає, задача дає робочий каркас нормалізації; увімкнення
  (`is_enabled`) лишається за наявністю approved-контенту (не предмет цієї задачі).

## Definition of Done

- [ ] Spike OQ-7 зафіксовано: джерела й ліцензії для en/de/nl задокументовані, профілі заведені в seed.
- [ ] Жодного літерала `"pl"` у `SearchFormsProjection`/імпортері; мова береться з конфігу.
- [ ] Integration-тест: пошук за формами й нормалізація для `pl` і ще однієї мови дають мово-свідомий результат.
- [ ] Правила de/nl (рід, артиклі, капіталізація, складені слова) покриті unit-тестами нормалізації.
- [ ] PR ≤500 LOC (інакше розбити на T07a/T07b, як у заголовку).
