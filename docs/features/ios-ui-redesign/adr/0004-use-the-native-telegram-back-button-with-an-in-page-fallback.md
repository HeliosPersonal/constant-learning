# 0004 — Нативна кнопка «Назад» Telegram із запасним посиланням на сторінці

- **Status:** Accepted
- **Date:** 2026-11-04
- **Deciders:** Viacheslav Melnichenko

## Context

Кожен вкладений екран мав власне посилання «← На головну» чи «← До «Сьогодні»» на сторінці. Воно займало вертикальне місце, а в Telegram є нативна кнопка `BackButton` у шапці, яку користувачі вже знають ([US-02](../PRD.md#4-user-stories)). Не всі клієнти її підтримують, а в браузері й тестах Telegram немає.

## Decision drivers

- Звільнити місце на екранах ([AC-02](../PRD.md#5-acceptance-criteria)).
- Працювати без Telegram: у браузері під час розробки й у тестах ([AC-03](../PRD.md#5-acceptance-criteria)).
- Вкладені екрани не повинні конфліктувати за єдину нативну кнопку.
- Не дозволяти повернення, поки небезпечний запит триває ([AC-04](../PRD.md#5-acceptance-criteria)).

## Considered options

1. **Лишити посилання «←» на сторінці** — просто, але займає місце й не нативно.
2. **Лише нативна кнопка** — ламає розробку й тести поза Telegram та старі клієнти.
3. **Компонент `BackButton`: нативна кнопка, якщо Telegram її підтримує (версія 6.1+), інакше текстове посилання.** Єдиний обробник нативної кнопки; екрани реєструються у стеку, активним є останній змонтований.

## Decision outcome

**Chosen:** Option 3. Компонент [BackButton](../../../../ConstantLearning.MiniApp/src/components/BackButton.tsx) показує нативну кнопку при першому змонтованому екрані, ховає її після останнього й викликає обробник верхнього екрана; `disabled` блокує повернення. Поза Telegram рендерить звичайну кнопку-посилання. Глобальні стилі кнопок Telegram UI обмежено через `:where(:not(.ios-plain))`, щоб власні кнопки не успадковували їх.

## Consequences

**Positive**
- Вертикальне місце звільнено; навігація як у системних застосунках; один компонент на всі екрани.
- Той самий код працює в Telegram, браузері й тестах.

**Negative / trade-offs**
- Поведінку на справжніх клієнтах iOS/Android не перевірено ([PRD §8](../PRD.md#8-open-questions)); різні версії Telegram можуть відрізнятися.
- Стек обробників — спільний стан модуля: помилка в порядку монтування змінила б, який екран отримає «Назад».
