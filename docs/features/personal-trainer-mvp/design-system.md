# Дизайн-система Mini App — Everforest

Дата: 2026-11-01. Статус: **Everforest затверджено користувачем без зауважень**. Фронтенд ще не реалізовано. Цей документ і [theme-tokens.json](./design/theme-tokens.json) визначають дизайн для реалізації; [ADR-0013](./adr/0013-use-everforest-with-manual-light-dark-themes.md) замінює попереднє правило SAD про виключне успадкування кольорів Telegram.

## Погоджені вимоги

- Користувач може обрати світлу або темну тему Mini App.
- Кольори мають бути приглушеними, без неонових акцентів і великих яскравих заливок.
- Обрано адаптацію Everforest із двома темами: світлою та темною.

## Палітра й перевірки

Світла тема використовує кремовий фон та оливковий акцент; темна — сіро-зелений фон і м'який зелений акцент. Основою є Everforest medium, світла картка використовує bg0 hard. Кольори кнопки, допоміжного тексту та помилки адаптовано для контрасту в інтерфейсі. Точні значення й опис адаптацій — у [theme-tokens.json](./design/theme-tokens.json).

Для обох тем перевірено основний і допоміжний текст на фоні та картці, текст кнопки на її заливці, текст помилки на картці: усі 12 пар мають контраст щонайменше 4.5:1. Колір фокуса й контури контролів мають контраст щонайменше 3:1 до фону та картки. Пороги перевірено до округлення. Це перевірка токенів; поведінка компонентів, portal, focus і disabled ще перевірятиметься під час реалізації.

Джерела: [Everforest: палітра](https://github.com/sainnhe/everforest/blob/master/palette.md), [реалізація варіантів](https://github.com/sainnhe/everforest/blob/master/autoload/everforest.vim), [W3C: контраст тексту](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html).

## Поведінка тем

У налаштуваннях — два варіанти: **Світла** і **Темна**, із текстовою позначкою вибраного. Вибір застосовується одразу до всіх екранів, полів, модальних вікон і повідомлень та зберігається локально на пристрої. Синхронізація між пристроями не потрібна для першої версії.

До першого ручного вибору Mini App використовує `Telegram.WebApp.colorScheme`; за відсутності Telegram — `prefers-color-scheme`, далі світлу тему. Після ручного вибору подія `themeChanged` не перевизначає вибір користувача. Збережену тему потрібно застосувати до першого видимого рендера, щоб уникнути світлого спалаху. Якщо локальне сховище недоступне, вибір працює в поточному запуску.

Семантичні токени продукту є джерелом кольорів компонентів. UI kit Telegram залишається базою компонентів; перед реалізацією перевірити його механізм перевизначення теми, включно з portal-компонентами. Колір фону й шапки оболонки Mini App синхронізується через підтримувані Telegram API; для старих клієнтів потрібен fallback за версією. Це не змінює глобальну тему Telegram.

Джерело для інтеграції: [Telegram Mini Apps — colorScheme, themeChanged, setHeaderColor, setBackgroundColor](https://core.telegram.org/bots/webapps). API не гарантує однакової поведінки всіх версій клієнтів.

## Спільні основи

- Типографіка: системний sans-serif зі знаками української та польської абеток; основний текст 16 px / 24 px, допоміжний 14 px / 20 px, заголовки 24 px / 32 px. Власні шрифтові файли для MVP не потрібні.
- Відступи: шкала 4, 8, 12, 16, 24, 32 px. Радіуси полів і кнопок 12 px, карток 16 px. Мінімальна зона натискання 44 × 44 px.
- Акцент використовується для головної дії, вибору та фокуса. Навчальний результат передається текстом та іконкою разом із кольором. Помилка не заливає весь екран червоним.
- Набір компонентів: кнопка, поле відповіді, картка слова, блок результату, progress, вкладки, перемикач теми, toast/dialog. Для кожного описати доречні стани loading, disabled, focus, error, empty.
- Анімації короткі й необов'язкові для розуміння стану; враховувати `prefers-reduced-motion`. Зміна теми не скидає введену відповідь або поточну картку.

## Затверджені кольори

| Токен | Світла | Темна |
|---|---|---|
| `background` | `#fdf6e3` | `#2d353b` |
| `surface` | `#fffbef` | `#343f44` |
| `text` | `#5c6a72` | `#d3c6aa` |
| `muted` | `#657166` | `#a7b2a8` |
| `accent` | `#52652f` | `#a7c080` |
| `onAccent` | `#fffbef` | `#2d353b` |
| `border` | `#bdc3af` | `#56635f` |
| `danger` | `#ad4250` | `#f29c9d` |

`border` призначено для декоративних роздільників і карток. Межі полів та інших елементів, розпізнавання яких залежить від контуру, використовують `controlBorder = muted`. Кільце фокуса — `focusRing = accent`, 2 px із відступом 2 px. Для успіху використовується `success = accent` разом з іконкою та текстом; для помилки — `danger` разом із поясненням.

Кнопка: default — accent/onAccent; hover — додаткова внутрішня рамка onAccent без зміни базових кольорів; pressed — втиснута рамка; loading — індикатор і підпис без зміни ширини; disabled — surface/muted і недоступна дія. Другорядні кнопки використовують surface/text і controlBorder. Помилка поля змінює контур на danger та додає пояснення. Позначка активної вкладки містить текст або форму, тому не залежить лише від відтінку.

Локальний ключ `constant-learning.theme.v1` приймає лише `light` або `dark`. Некоректне значення ігнорується. Компоненти використовують семантичні токени; HEX не дублюються по екранах.
