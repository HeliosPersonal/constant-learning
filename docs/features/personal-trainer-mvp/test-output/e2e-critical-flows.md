Дата: 2026-11-02. Джерела: [T46](../tasks/T46-e2e-critical-flows.md), [тест-план](../test-plan.md), [PRD](../PRD.md), [локальні команди](../../../../ConstantLearning.MiniApp/README.md).

## Перевірений результат

Незалежний прогін координатора `npm run test:e2e`: **4/4**, 17,7 с, без повторів runner. Браузер звертався до справжнього Kestrel із production DI, маршрутизацією, HMAC-автентифікацією й зібраною Mini App. PostgreSQL 16 створено Testcontainers; застосовано справжні EF-міграції. API не підміняли. SDK Telegram імітується через `mockTelegramEnv`; токен синтетичний.

| Сценарій | Результат |
|---|---|
| AC-01: онбординг → «Сьогодні» | пройдено |
| AC-03 та AC-12: повторення перед новими словами, правильна оцінка, повне завершення заняття | пройдено; три покази й три перевірки нових слів |
| AC-17: typo → оскарження → нейтралізація → перезавантаження → продовження | пройдено; SQL підтвердив незмінний mistake_typo, окрему нейтралізацію, answer_dispute/in_editor_queue та відсутність verification_jobs |
| AC-34: повідомлення з картки словника | пройдено; підтвердження прийняття показано після справжнього API |

Фіксований тестовий час — 2026-10-31 09:00 UTC; ідентичності синтетичні, кожен сценарій має окремого learner. Тестова фабрика вимикає імпорт початкового словника, webhook і Quartz hosted service та створює власні чотири записи після міграцій. Production-код не змінюється. Необов’язковий `E2E_SYSTEM_CLOCK=1` призначений для окремих локальних запусків; звичайні E2E використовують фіксований час.

Початковий незалежний запуск виявив несумісний запис Windows named pipe у дочірньому Docker CLI. Runner тепер нормалізує лише його `DOCKER_HOST`, зберігаючи потрібний .NET-клієнту формат. Фінальний прогін вище виконано після виправлення. Локальні trace, screenshot і video зберігаються при помилці.

Додатково: незалежні lint/typecheck зелені; scoped форматування host зелене. Виконавець перевірив host build та 232/232 Vitest. Зберігається початковий NU1903 для Microsoft.OpenApi 2.0.0. Перевірки frontend/E2E у CI не додавали.

Ручний smoke у справжньому Telegram з окремим тестовим ботом і HTTPS-тунелем **не виконано**. Користувач підтвердив відсутність тестового середовища й погодив залишити ручний smoke заблокованим. [T46](../tasks/T46-e2e-critical-flows.md) має статус blocked саме через цю частину DoD. Інструкція для ручної перевірки наведена в [README Mini App](../../../../ConstantLearning.MiniApp/README.md).
